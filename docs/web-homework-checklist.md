# web 대비 homework 구현 체크리스트

`web` 프로젝트를 기준으로 `homework` 프로젝트의 기능과 스타일 차이를 정리한다.

## 우선 구현 기능

- [x] 다크모드
  - [x] 라이트·다크모드 색상 변수 구성
  - [x] 토글 선택 시 전체 화면 색상 변경
  - [x] 목록과 상세 화면에 동일하게 적용
  - [x] 새로고침 후 선택 상태 유지
- [x] 사진보관함
  - [x] 보관함 탭 전환
  - [x] 사진 목록 표시
  - [x] 기본·가로형·세로형 비율 선택
- [ ] 페이지네이션
  - [ ] 일기 목록을 페이지 단위로 나누기
  - [ ] 이전·다음·페이지 번호 이동
  - [ ] 감정 필터나 검색어 변경 시 첫 페이지로 이동
- [x] 작성·수정 취소 확인 모달
  - [x] 닫기 버튼 선택 시 확인
  - [x] ESC 입력 시 확인
- [x] 목록과 상세의 삭제 확인 모달 통일

## 기능 보완

- [x] 수정 완료 안내를 완료 모달로 표시
- [ ] 클립보드 복사 실패 안내와 대체 처리
- [x] 브라우저 저장 데이터가 잘못된 경우 복구
- [ ] 헤더와 푸터를 공통 구성요소로 분리해 재사용
- [ ] 일기 제목과 내용 출력 시 HTML 특수문자 처리
- [ ] 검색 결과가 없을 때 전용 안내 문구 표시
- [x] 제목·내용 검색과 감정 필터 동시 적용
- [ ] 초기 예시 일기 제공 여부 결정

## 스타일 보완

- [ ] Pretendard 계열 기본 글꼴 적용
- [x] 카드에 마우스를 올렸을 때 이미지 확대·흐림 적용
- [ ] 카드에 마우스를 올렸을 때 그림자 적용
- [ ] 카드에 마우스를 올렸을 때 `상세 보기` 표시
- [ ] 중간 화면 너비에서 카드 열 수와 너비 보정
- [ ] 입력창과 선택창의 키보드 포커스 스타일 적용
- [ ] favicon 추가

## 현재 구현 완료

- [x] 감정 필터
- [x] 제목·내용 포함 검색
- [x] 일기 등록 후 목록 즉시 갱신
- [x] 일기 등록·수정·삭제
- [x] 회고 등록과 회고 위치 이동
- [x] 내용 복사 토스트
- [x] 모달 바깥 클릭과 ESC 입력 처리
- [x] 모달 표시 중 뒷배경 스크롤 차단
- [x] 맨 위로 이동 버튼
- [x] 고정 헤더와 고정 필터
- [x] 모바일 카드 2열 배치

## 유지할 과제 기준

- 모바일 카드 2열은 08/06 과제 요구사항이므로 `web`의 1열 배치를 따라가지 않는다.
- 고정 헤더와 고정 필터는 `homework`에 구현된 과제 기능을 유지한다.
